# Bundled font licenses

All fonts bundled with this add-on are licensed under the **SIL Open Font
License, Version 1.1** (<https://scripts.sil.org/OFL>). Each family remains under
its original license and copyright; this add-on merely repackages the upstream
TrueType sources as woff2 for delivery.

| Family | File | Upstream source |
|--------|------|-----------------|
| Literata | `Literata-var.woff2` | https://github.com/google/fonts/tree/main/ofl/literata |
| Inter | `Inter-var.woff2` | https://github.com/google/fonts/tree/main/ofl/inter |
| Noto Sans | `NotoSans-var.woff2` | https://github.com/google/fonts/tree/main/ofl/notosans |
| Noto Sans TC | `NotoSansTC-var.woff2` | https://github.com/google/fonts/tree/main/ofl/notosanstc |
| New Tegomin | `NewTegomin-Regular.woff2` | https://github.com/google/fonts/tree/main/ofl/newtegomin |
| IBM Plex Sans | `IBMPlexSans-var.woff2` | https://github.com/google/fonts/tree/main/ofl/ibmplexsans |

The woff2 files were produced from the upstream `[...].ttf` variable sources
(upright only) with `fontTools` (`flavor = "woff2"`); no glyph or metadata
changes were made. Reserved Font Names from each family's OFL apply.
